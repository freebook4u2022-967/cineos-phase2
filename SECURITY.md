# Security Policy

## Supported versions

CINEOS Phase 2 is pre-release software. Security fixes are applied to the
latest revision of the default branch; older revisions are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository
hosting service's private vulnerability reporting feature. If that feature is
unavailable, contact the repository owner through a private channel and ask for
a secure reporting method without including sensitive details in the first
message.

Include the affected revision, reproduction steps, potential impact, and any
known mitigations. Maintainers will acknowledge a report as soon as practical,
coordinate validation and remediation, and arrange disclosure after a fix is
available. Please allow a reasonable remediation period before disclosure.

Never include secrets, personal data, or destructive proof-of-concept material
that is not necessary to understand the report.
