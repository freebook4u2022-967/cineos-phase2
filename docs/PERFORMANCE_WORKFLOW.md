# Performance workflow

1. Approve character rights, CineDNA expressions, motion references, and dialogue audio.
2. Build a performance plan from a NOVA shot and AudioProject.
3. Review beats, expression/lip-sync timelines, gestures, blocking, eye-lines, and warnings in Studio.
4. Lock manual changes and validate continuity with adjacent plans.
5. Negotiate renderer capabilities; use only an approved fallback policy.
6. Export the canonical hashed JSON and pass its ID and targets into conditioning.

Never infer personality or demographic traits, silently discard dialogue/identity, or use unapproved real-person face or voice assets.
