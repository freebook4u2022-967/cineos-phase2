# Performance planning

CINEOS performance plans connect NOVA dramatic intent to timed, renderer-independent beats, facial targets, gestures, body blocking, eye-lines, emotion, and dialogue. Character identity and custom expressions must come from approved CineDNA; manual locks survive rebuilds. Capability validation fails unsupported requests unless a named fallback policy explicitly approves and records the loss.

Use `cineos performance build SHOT --audio-project audio.json --output performance.json`, then `cineos performance validate performance.json`.
