# Alpha limitations

CINEOS 0.1 Alpha is an evaluation release, not production-ready software. The
preview path emits deterministic inspection artifacts and does not establish
visual quality. CINEOS makes no Seedance-level claim. Real renderer behavior,
GPU performance, cross-machine timing reproducibility, native installers, and
production media delivery are not guaranteed. No AI weights, copyrighted media,
or fonts are bundled. Baselines require manual review and benchmark failures
remain visible.
